1)What is JSX, and why is it used?
JSX is used to write HTML code inside JavaScript.It makes React UI easy and readable.

2)What is the difference between State and Props?
State is changeable data inside a component, on the contrary Props are read-only data passed from parent to child.

3)What is the useState hook, and how does it work?
useState is a hook that helps functional components store and update data.

4)How can you share state between components in React?
State is shared by keeping it in the parent component and sending it using props.

5)How is event handling done in React?
Event handling is done by using camelCase events and functions such as onClick.
